## О проекте

QSFM - Минималистичный файловый менеджер, сочетающий базовую функциональность и лёгкость. Поддерживаемые платформы: Linux, FreeBSD.

## Возможности

**Настройка файлового менеджера**
- **scale** (0.5–10.0) - масштаб интерфейса (1.0 = 100%)
- **font** - шрифт (имя fontconfig или путь к .ttf/.otf), моноширинный
- **font_size** (6–72) - размер шрифта при scale=1.0
- **window_width** (300–10000) - ширина окна при запуске
- **window_height** (200–10000) - высота окна при запуске
- **sidebar_width** (100–1000) - ширина боковой панели
- **icon_size** (16–256) - размер значков файлов/папок
- **place_icon_size** (8–128) - размер значков в панели «Места»
- **up_icon_size** (8–128) - размер значка кнопки «вверх»
- **cell_width** (48–400) - ширина ячейки файла в сетке
- **show_hidden** (bool) - показывать скрытые файлы при запуске
- **scroll_lines** (1–50) - рядов сетки за шаг колеса мыши
- **date_format** - формат даты (strftime)
- **start_dir** - папка при запуске (~ = домашняя)
- **opener** - программа открытия файлов
- **terminal** - команда «Открыть в терминале»; пусто = подсказка
- **color_bg** - фон списка файлов и полей ввода
- **color_toolbar** - фон верхней панели и строки состояния
- **color_sidebar** - фон боковой панели и диалогов
- **color_border** - линии и рамки
- **color_text** - текст
- **color_text_dim** - неактивный текст, подсказки
- **color_selection** - фон выделения/пункта меню/заголовка диалога
- **color_selection_text** - текст и значки на выделении
- **color_place_selection** - фон текущего места в панели
- **color_focus** - рамка активного поля ввода
- **color_button** - фон кнопок
- **color_menu** - фон контекстного меню
- **color_scrollbar** - полоса прокрутки, индикатор прогресса
- **color_scrollbar_thumb** - ползунок прокрутки
- **color_icon** - значки
- **color_icon_dim** - неактивные значки

Всё задаётся в `~/.config/QSFM/config.conf` после первого запуска.

## Сборка / Запуск

**FreeBSD**
```
sudo pkg install xcb libxcb xcb-image xcb-keysyms xcb-cursor freetype2 fontconfig pkgconf gmake
gmake

./QSFM
```

**Ubuntu/Debian**
```
sudo apt install build-essential pkg-config libxcb1-dev libxcb-image0-dev libxcb-keysyms1-dev libxcb-cursor-dev libfreetype-dev libfontconfig1-dev
make

./QSFM
```

## Технологии

- C11, XCB, FreeType2, Fontconfig
